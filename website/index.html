macOS

Speak. It's already written.

Mispr Flow is a free and fast dictation app for Mac, with agent mode. Hold a key, talk, and the text lands in the field you are using.

Download for Mac

MisprFlow.dmg · Apple silicon and Intel · MIT

Agent mode

A spoken task becomes text in the field you are already using.

Agent Task

Speak a task. The app pastes a finished draft. The draft is grounded in the frontmost app and a screenshot. The model returns only the text to paste.

Agent Edit

Select text, speak the change, and the selection is replaced.

Agent mode uses the model you configure. There is no Mispr Flow account.

Three steps

01

Download the DMG

Open MisprFlow.dmg and drag the app to Applications.

02

Add a Groq key

Create a free key at groq.com.

03

Talk

Hold Fn to talk, or tap Command-Fn to start and stop.

Dictation

Custom shortcutsHold to talk, or tap to toggle. A longer toggle can latch on from hold mode.
Context-aware cleanupNearby app context helps names, terms, and phrases come out spelled correctly.
Custom vocabularyKeep the names and jargon you actually use.
Voice macrosA spoken command can paste text you defined ahead of time.
Your own API base URLGroq is the default. Point transcription and chat at another compatible endpoint when you want to.

Privacy

There is no Mispr Flow server. Audio and text go only to the transcription and model provider you configure.
